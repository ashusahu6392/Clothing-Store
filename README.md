# 👗 Clothing Store

A modern, responsive **static clothing store website** — **FemmeWardrobe** — built with HTML, CSS, and Bootstrap. A clean open-source front-end template for fashion and e-commerce websites.

---

## 🌐 Live Pages

| Page | File | Description |
|------|------|-------------|
| Home | `index.html` | Hero, featured products, promotions, testimonial |
| Shop | `shop.html` | Product listings |
| About | `about.html` | Brand story |
| Contact | `contact.html` | Contact form / info |

---

## ✨ Features

- **Responsive navbar** with centered logo, left navigation links, and right icons (search & cart)
- **Hero section** — full-width banner with headline and call-to-action
- **Most Popular** — 4-column product grid with size (XS–XL) and color selectors
- **Newest Products** — second product grid showcasing latest arrivals
- **Promotional sections** — styled feature banners for Bags and Blazer collections
- **Customer testimonial** — 5-star review section
- **Trust badges** — Secure Payments, Free Shipping, Easy Returns, Order Tracking
- **Footer** — multi-column layout with Menu, Categories, Resources, and Social Media links
- Fully responsive using **Bootstrap grid**
- Custom fonts: **Montserrat** & **Cormorant Garamond** (Google Fonts)
- Icons via **Font Awesome 7**

## 🚀 Getting Started

No installation or build tools required.

### 1. Clone the repository

```bash
git clone https://github.com/ashusahu6392/Clothing-Store.git
```

### 2. Open in your browser

```bash
cd Clothing-Store
```

Then simply open `index.html` in any modern browser — double-click the file or drag it into your browser window.

---

## 🎨 Customization

- **Brand name / logo** — Replace `assets/images/logo-01.svg` with your own logo
- **Product images** — Swap images in `assets/images/` with your products
- **Colors & fonts** — Edit `css/style.css` to match your brand palette
- **Product names & prices** — Update the text directly in the HTML files
- **Categories** — The store includes Casual, Work & Office, Activewear, and Evening Dresses — edit as needed
